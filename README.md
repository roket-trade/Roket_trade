# Candlestick Capital

Create a modern, dark-themed crypto trading landing page. The hero section must include a simulated candlestick chart animation using pure CSS/Canvas or the lightweight-charts npm package (no external API). The animation should show fake green and red candles moving upward, with pop-up labels like 'BUY' and 'Profit +$25' appearing sequentially. Do not use any real market data. Add a pricing section below with 4 static plans: Plan 1 ($60 deposit, $1 daily), Plan 2 ($120 deposit, $3 daily), Plan 3 ($180 deposit, $4.5 daily), Plan 4 ($250 deposit, $8 daily). Include a 'Get Started' button that redirects to the signup page.
